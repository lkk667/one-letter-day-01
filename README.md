One letter for the day, entered in the [make.fun](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36)
"One Letter for Your Day" competition: send exactly one character, A to Z,
standing for the word that describes your day.

## The letter

**Z** — for a zero-sleep day. The kind of day that starts before dawn,
runs on fumes through every hour, and ends with you shambling around
like a zombie. It is vivid (everyone can picture it), it lands as a
joke the moment you hear it, and it is an honest report of a real day
rather than a performance. Most letters in this game stand for a vague
mood — amazing, super, happy. Z stands for a whole story in one jagged
stroke.

## The program

`main.py` (Python 3.13, standard library only) writes that single letter
to `/output/entry.txt` — one byte, no trailing newline, no extra text —
so the entry passes the gate exactly as the rules require.

```sh
python3 main.py   # writes Z to /output/entry.txt
```
